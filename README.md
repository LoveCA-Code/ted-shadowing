# TED Shadowing

TED 강연을 **문장 단위로 듣고 → 멈추고 → 따라 말하는** 쉐도잉 웹앱입니다. 아이폰 홈 화면에 추가해서 앱처럼 씁니다.
단어나 표현을 탭하면 단어장에 모이고, 안키처럼 간격 반복으로 복습합니다.

## 구조

```
index.html / style.css / app.js   웹앱 (빌드 과정 없음)
sw.js, manifest.webmanifest       홈 화면 앱(PWA) 설정
talks/index.json                  강연 목록
talks/<영상ID>.json               문장 구간 + 한국어 해석
tools/add_talk.py                 유튜브 자막 → 구간 JSON 변환 스크립트
```

## 강연 추가하기 (PC)

```bash
pip install youtube-transcript-api      # 처음 한 번
python tools/add_talk.py https://www.youtube.com/watch?v=영상ID
```

- TED 공식 유튜브 채널 영상은 사람이 만든 영어·한국어 자막이 있어 문장 구분이 정확합니다.
- 한국어 자막이 없으면 유튜브 자동 번역을 쓰고, `--no-ko`를 붙이면 해석을 받지 않습니다.
- 추가한 다음 GitHub에 올리면(push) 아이폰에도 바로 보입니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```
→ http://localhost:8765

## 아이폰에서 쓰기 (GitHub Pages)

1. GitHub에 저장소를 만들고 이 폴더를 push합니다.
2. 저장소 Settings → Pages → Branch: `main` / `(root)` → Save
3. 아이폰 Safari에서 `https://<아이디>.github.io/<저장소>/`를 엽니다.
4. 공유 버튼 → **홈 화면에 추가**

## 사용법

| 조작 | 동작 |
|---|---|
| ▶ | 현재 구간부터 재생 (구간 재생 → 멈춤 → 따라 말하기 → 반복 → 다음 구간) |
| ⏮ ↺ ⏭ | 이전 구간 / 현재 구간 다시 / 다음 구간 |
| ✓ 외움 | 현재 문장을 외운 문장으로 표시 (목록에 진행률 표시) |
| 문장 번호 탭 | 그 문장으로 바로 이동해 재생 |
| 단어 탭 | 단어 시트 열림 → "앞/뒷 단어 포함"으로 숙어 선택 → 뜻 메모 → 저장 |
| 반복 | 1·2·3·5회·∞ |
| 따라할 시간 | 구간 길이의 ×1~×2만큼 멈춤 (따라 말하는 시간) |
| 영어 가림 | 텍스트를 흐리게 처리해 듣기만으로 따라 하기 (탭하면 보임) |
| 해석 | 한국어 해석 보이기/숨기기 |

- 영상 화면을 직접 눌러 재생하면 **연속 재생 모드**가 되고, 현재 문장이 자동으로 따라갑니다.
- 아이폰에서는 처음 한 번 영상 화면을 직접 탭해야 재생될 수 있습니다.

## 데이터 저장

단어장과 진행 상황은 **기기 안(localStorage)에만** 저장됩니다.
- Safari와 홈 화면 앱은 저장소가 따로라서, 홈 화면 앱으로만 쓰는 것을 권장합니다.
- 단어장 탭 → **내보내기**로 가끔 백업 파일을 저장해 두세요. 다른 기기에서는 **가져오기**로 합칠 수 있습니다.
